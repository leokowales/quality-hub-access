# QualityHub — acesso de homologação

Canal de autorizações exclusivas das instalações QualityHub (Homologação).

Publicar somente envelopes cifrados e assinados em `authorizations/<identificador>.json`, após conferir e-mail e código da instalação. Não publicar códigos QH2, cadastro, e-mail em texto aberto, senhas, tokens ou chaves privadas.

O aplicativo usa banco/perfil de homologação local separados do uso operacional. Cada nova instalação precisa de aprovação própria. Extensões e revogações usam revisões crescentes; manter a revisão mais recente, inclusive revogada.
