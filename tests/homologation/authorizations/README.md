# Autorizações de homologação

Enviar aqui somente o arquivo `<identificador>.json` gerado pela ferramenta privada do mantenedor, após conferir e-mail e código da instalação. O conteúdo deve ser cifrado e assinado. Cadastro, códigos QH2, senhas e chaves privadas nunca devem ser enviados.

Para estender ou revogar, gerar uma revisão nova e substituir o JSON com o mesmo nome. Não excluir um documento revogado nem restaurar revisão antiga.
